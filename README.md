# Adarsh Sah - Personal Portfolio Website

![Portfolio Preview](./public/vite.svg)

A fully responsive, animated personal portfolio website built from scratch.

## Description

This portfolio showcases my skills, experience, and projects as a Data Science Student and Data Engineering Enthusiast. It features a modern, analytical, and premium dark-futuristic design.

### Key Features
- **3D Interactive Elements**: Built using CSS 3D transforms (`perspective-1000`, `rotateX/Y`) and Framer Motion for highly performant, GPU-accelerated interaction without heavy 3D libraries.
- **Hero Data Orb**: A custom-built, continuously orbiting 3D data analytics orb visualization in the Hero section.
- **Glassmorphism UI**: Beautiful semi-transparent frosted glass cards with gradient borders and glowing shadow effects.
- **Accessibility & Performance**: The application implements accessible color contrast (e.g. `#e2e8f0` text on `#0f172a` backgrounds) and strictly adheres to web accessibility standards, including full support for the `prefers-reduced-motion` CSS media query which instantly disables 3D rotations for accessibility.

## Setup Instructions

To run this project locally:

1. **Clone the repository**
   ```bash
   git clone https://github.com/Adarsh12325/portfolio.git
   cd personal-portfolio-website
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```
   The application will be available at `http://localhost:5173`.

4. **Build for production**
   ```bash
   npm run build
   ```
   The production-ready files will be generated in the `dist` folder.
